# RoleLinked branding

## Product name

- Written name: **RoleLinked**
- Repository slug: `rolelinked`
- Intended domain: `rolelinked.com`
- Short mark: `rl`

## Positioning

> A local-first AI career command center.

RoleLinked connects role discovery, evidence-based application preparation, pipeline tracking, and interview practice while keeping the user in control.

## Visual system

- Primary: deep teal (`#0F766E`)
- Highlight: bright teal (`#14B8A6`)
- Secondary: indigo (`#4F46E5`)
- Light background: cool off-white (`#F6F8F8`)
- Dark background: blue-black (`#071211`)

Do not imitate LinkedIn's wordmark, blue palette, `in` icon, or interface. RoleLinked is not affiliated with LinkedIn.

## Upstream attribution

Every public distribution must retain `LICENSE` and `NOTICE.md`. Product copy must describe RoleLinked as an independent derivative of Career Ops until the codebase has been replaced with independently developed implementations where appropriate.

After creating the public GitHub repository, set
`NEXT_PUBLIC_ROLELINKED_REPO` to its `owner/repository` value when building the
dashboard. This enables the in-app bug reporter without directing derivative
issues to the Career Ops upstream project.
